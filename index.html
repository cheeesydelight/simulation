Why this one survives contact with reality

Compliant by design

Sanctioned data, not blocked scrapers

Fares come from an official flight-search API. No CAPTCHA bypass, no proxy rotation, no login walls.

robots.txt + rate limits

The one scraper we keep checks robots.txt before every run and waits six seconds between requests.

Nothing faked silently

Any value we did not collect is labelled simulated — on the chart, in the database, in the API response.

Backtested against DGCA

The index is compared with official published fare data so an evaluator can check our work, not trust it.

APIx(t)  =  100  ×  Σr  wr  ×  ( Pr(t)  /  Pr(base) )
r = route in the fixed basket w = DGCA passenger-traffic share P = mean fare across booking windows
